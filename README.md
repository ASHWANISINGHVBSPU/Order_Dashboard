# Order_Dashboard

## 📌 Project Overview
The objective of this project is to analyze sales performance, track key order metrics, and identify regional or category-wise trends. By leveraging Excel formulas and Pivot Tables, raw data is processed into a dynamic dashboard for data-driven decision-making.

## 📂 Repository Structure
* *Excel Sheet.xlsx* – Contains the primary raw dataset, data cleaning processes, and structural formulas.
* *Order_Pivot Table.xlsx* – Houses the interactive Pivot Tables, calculated fields, and the final analytical dashboard interface.

---

## 🚀 Key Features & Capabilities
* *Dynamic Pivot Tables:* Automated data aggregation to filter metrics by region, product category, and timeline.
* *KPI Matrix:* Live tracking of Total Sales, Revenue Margins, and Total Order Volume.
* *Interactive Charts:* High-impact charts linked with Slicers for an interactive user experience.
* *Data Sanitization:* Handled missing values, formatted dates, and removed duplicate entries to ensure accuracy.

---

## 💻 How to Explore the Project
Since GitHub does not natively render interactive Excel sheets or Pivot Tables, please follow these steps to experience the interactive dashboard:

1. *Clone or Download* this repository to your local machine.
2. Open *Order_Pivot Table.xlsx* using *Microsoft Excel* (Desktop version recommended for full functionality).
3. Use the built-in *Slicers and Timelines* to filter through the charts dynamically.
